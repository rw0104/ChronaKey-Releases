# ChronaKey v0.1.0-alpha.1

这是 ChronaKey 的第一个公开测试版本。

ChronaKey 是一款在本地运行的 2FA 验证器。它支持扫描二维码、选择二维码图片、粘贴
`otpauth://` URI 和手动输入 Base32 密钥。当前提供 Android 和 Windows 测试版本。

> 当前版本仍在测试阶段。建议先添加一个不重要的账号体验，并继续保留原来的验证器和
> 恢复码。

## 下载

- **Android 手机**：下载 `ChronaKey-Android-release.apk`。
- **Windows 10/11 x64**：下载 `ChronaKey-Windows-x64-unsigned-setup.exe`。

## 安装说明

Android APK 已使用 ChronaKey 长期 RSA-4096 Release 证书签名。如果手机安装过此前提供的
早期测试包，由于签名不同，无法直接覆盖安装。请先导出 Vault 备份，确认原验证器和恢复码
仍可用，再卸载旧版并安装新版。

Windows 安装程序尚未进行 Authenticode 签名，Windows 可能显示“未知发布者”或
SmartScreen 提示。请只从本仓库下载，并先核对 `SHA256SUMS`。

Android 签名证书 SHA-256：
`638d5a56b337613637e475d830440f81250c049dc3af091be0206c64b6dc62fd`

## 建议体验这些功能

- 创建、解锁和锁定本地 Vault。
- 扫描二维码、选择二维码图片、粘贴 `otpauth://` URI 或输入 Base32 密钥。
- 检查 TOTP 显示、复制、账户排序和删除。
- 验证备份恢复及错误输入处理。

请先使用不重要的测试账户，并继续保留常用账号的原验证器和恢复码。发现问题时不得上传真实二维码、
Base32 密钥、Vault、恢复密码或恢复码。
