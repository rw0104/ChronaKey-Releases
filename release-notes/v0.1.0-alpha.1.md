# ChronaKey v0.1.0-alpha.1

这是 ChronaKey 的第一个公开测试版。

如果你想体验一个不用注册账号、把 2FA 密钥留在自己设备上的身份验证器，现在可以在
Android 和 Windows 上安装测试。它支持扫码、读取二维码图片、粘贴 `otpauth://` URI 和
手动输入 Base32 密钥。

> 这是 Alpha 版本。请先使用测试账户，不要删除原验证器里的生产密钥和恢复码。

## 应该下载哪个文件？

- **Android 手机**：下载 `ChronaKey-Android-release.apk`。
- **Windows 10/11 x64**：下载 `ChronaKey-Windows-x64-unsigned-setup.exe`。

## 安装时需要注意

Android APK 已使用 ChronaKey 长期 RSA-4096 Release 证书签名。此前安装过 Debug APK 的
手机无法直接覆盖升级：请先在 Debug 版导出 Vault 备份，确认原验证器和恢复码仍可用，
再卸载 Debug 版并安装 Release APK。

Windows 安装程序尚未进行 Authenticode 签名，Windows 可能显示“未知发布者”或
SmartScreen 提示。请只从本仓库下载，并先核对 `SHA256SUMS`。

Android 签名证书 SHA-256：
`638d5a56b337613637e475d830440f81250c049dc3af091be0206c64b6dc62fd`

## 建议体验这些功能

- 创建、解锁和锁定本地 Vault。
- 扫描二维码、选择二维码图片、粘贴 `otpauth://` URI 或输入 Base32 密钥。
- 检查 TOTP 显示、复制、账户排序和删除。
- 验证备份恢复及错误输入处理。

请只使用测试账户，不要删除原验证器中的生产密钥。发现问题时不得上传真实二维码、
Base32 密钥、Vault、恢复密码或恢复码。

## 下载文件说明

- `SHA256SUMS`：安装包和构建元数据的 SHA-256 清单。
- `BUILD-METADATA.txt`：版本、源码提交、构建通道和签名边界。
