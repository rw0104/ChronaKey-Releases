# ChronaKey v0.1.0-alpha.1

首个公开的受控测试版本，供 Android 与 Windows 安装流程及核心 2FA 功能验证。

## 安装包

- `ChronaKey-Android-release.apk`：使用 ChronaKey 长期 RSA-4096 Release 证书签名的 APK。
- `ChronaKey-Windows-x64-unsigned-setup.exe`：Windows x64 NSIS 测试安装程序，尚未进行
  Authenticode 签名，Windows 可能显示 SmartScreen 警告。
- `SHA256SUMS`：上述安装包和构建元数据的 SHA-256 清单。
- `BUILD-METADATA.txt`：版本、源码提交、构建通道和安全边界。

Android 签名证书 SHA-256：
`638d5a56b337613637e475d830440f81250c049dc3af091be0206c64b6dc62fd`

此前安装过 Debug APK 的测试设备无法直接覆盖升级。请先在 Debug 版导出 Vault 备份，
确认原验证器和恢复码仍可用，再卸载 Debug 版并安装 Release APK。

## 测试范围

- 创建、解锁和锁定本地 Vault。
- 扫描二维码、选择二维码图片、粘贴 `otpauth://` URI 或输入 Base32 密钥。
- 检查 TOTP 显示、复制、账户排序和删除。
- 验证备份恢复及错误输入处理。

请只使用测试账户，不要删除原验证器中的生产密钥。发现问题时不得上传真实二维码、
Base32 密钥、Vault、恢复密码或恢复码。
